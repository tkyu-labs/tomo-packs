# ToyoNet-G pages and controls

The [ToyoNet portal](https://www.toyo.ac.jp/toyonet/) links to [ToyoNet-G](https://g-sys.toyo.ac.jp/portal/).
In ToyoNet-G, open `学生メニュー／Menu`, expand the group below and use the exact link. Most entries open a
child window. Bring it forward in the visible browser and wait for the page to settle. If one child is
already open, close it with the browser's ordinary close control before opening another. The portal
controls the navigation, including any temporary parameters.

| Question | Group and visible path | Expected screen |
| --- | --- | --- |
| My classes and recurring timetable | `履修・授業照会` → `履修登録確認表` | `曜日`, `時限`, `科目名`, `教室` and `キャンパス` columns. The identity and opening-year header is separate. |
| Course history or a grade | `履修・授業照会` → `履修・修得科目` → choose `履修・修得科目` → `検索` | One or more tables with `科目名`, `成績` and `開講期間`. An opening-year range and `過年度の不合格科目も表示する` are available when relevant. |
| Credits, shortfalls or GPA | `履修・授業照会` → `単位数集計表` → choose `単位数集計表` → `検索` | Requirement, delivery-mode, year/term and year-of-study tables. |
| Published timetable | `履修・授業照会` → `授業時間割表照会` → `全時限を表示` | Visible grids with `時間割`, `科目名` and `キャンパス`. |
| Campus cancellations | `休講（キャンパスごと）` or `休講（キャンパスごと）-英語表示-` → `休講照会（…）` for the location | Board with a date and course-name column. The labels repeat across the two groups. |

The browser-only expression checks the exact result route by mode. Use the navigation above, since course
history and credit result pages follow a form submission. Cite the stable portal link with the displayed title
and period, or the campus board's exact observed link. Leave query strings and session details out of citations.

## Other read-only destinations

| Student question | Where to look |
| --- | --- |
| Is there a makeup session? | `休講・補講` → `補講照会`. The portal landing boxes also label `休講情報` and `補講情報`. |
| Is a course assigned by lottery? | `履修登録` → `抽選実施科目一覧`. |
| Where do I find the exam time? | `学期末試験` → `試験時間割表照会`. The [official class guide](https://www.toyo.ac.jp/campuslife/student_support/lecture/) also points students to the official app for exam details. |
| What is my formal graduation decision? | `判定結果照会` → `卒業等各種判定結果照会`. |
| Where is a syllabus or instructor profile? | `履修・授業照会` → `シラバス・教員プロフィール`. If it fails, tell the student and offer the [public syllabus entry](https://g-sys.toyo.ac.jp/syllabus/) for syllabus lookup. Its live search availability can vary. |
| Where are instructor assignments? | `履修・授業照会` → `教員別担当授業一覧照会`. Search opens an instructor selection table. |
| Where is my qualification or minor? | `資格・副専攻` → `資格・副専攻照会`, or the separate qualification/minor option on the history and credit selection pages. |
| Where are placements or scholarships? | `実習` → `実習照会`, or `奨学金` → `奨学生情報一覧`. |

Use these entries for navigation guidance. Their populated result layouts were outside the verified
extraction scope. If an official public source answers the question, read it before asking the student
for more information and say when you used it as a fallback.
